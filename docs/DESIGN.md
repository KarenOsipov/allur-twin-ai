# Дизайн-система цифрового двойника завода АЛЛЮР

Фирменный стиль Allur — красные тона. Компоновка: светлое поле, белые
блоки с крупным скруглением, графитовые «deep»-блоки для главного, крупные тонкие цифры. Всё описано токенами в `frontend/src/styles/index.css`.

## Токены

| Текст | `ink` `ink-2` `ink-3` | #131826 · #3D4558 · #6B7489 |
| Тёмные блоки (винный графит) | `deep` `deep-2` `deep-3`, `deep-ink`, `deep-ink-2` | #1D1313 … текст #F8F1F0 / #BBA8A6 |
| Логотип Allur | `allur` | #FF3324 — только знак Allur |

## Шрифты

- **Outfit** (`.display`) — заголовки страниц (font-light, до 2.75rem) и все крупные цифры (extralight/light, 2.5–6.5rem).
- **Manrope** — текст интерфейса; подписи блоков — `.eyebrow` (13px, 600, без капса).
- Цифры — всегда моноширинные (`tnum`).

## Компоненты

| Компонент | Где | Правило |
|---|---|---|
| `Panel` | любой раздел | заголовок + подпись + действия; `tone="deep"` только для главного на странице |
| `Tile` | ряды показателей | подпись сверху, большая цифра, пояснение снизу; `alert` — красное кольцо |
| `Button` | действия | `primary` (красный) — одно главное действие в блоке; `deep`, `secondary`, `ghost`, `danger` |
| `Segmented` | переключатели периода и вида | пилюля, активный — белый |
| Верхняя навигация | `AppShell` | стеклянная шапка в два ряда: логотип Allur, завод, часы цеха, «ИИ-анализ», профиль; ниже — вкладки разделов с иконками (активная — белая пилюля, красная иконка и подчёркивание) |
| `ExportButton` | заголовок страницы | «Скачать» → боковая панель: PDF / Excel / PNG, кому, комментарий |
| `Drawer` | подробности | боковая панель на `<dialog>`; фон затемняется нейтрально, без красного |
| `StatusPill`, `Dot` | статусы | цвет всегда вместе с иконкой или словом |
| `CountUp` | изменяющиеся числа | плавно «доезжают» за 0,6 с |

## Движение

- Одна согласованная анимация появления: блоки страницы выезжают по очереди (`.rise`, шаг 60 мс).
- Знак логотипа собирается из двух деталей при загрузке.
- На схеме: бегущий поток по центру конвейера (только пока линия работает), мигающие индикаторы отказа, плавное движение кузовов.
- Фон статичный: мягкие красные пятна. При `prefers-reduced-motion` анимации отключаются.

## Логотип

Проект сделан для АО «Группа компаний АЛЛЮР» и оформлен как корпоративная система компании. Отдельного
знака продукта нет: в шапке стоит логотип Allur (`AllurLogo` — вектор по фирменному файлу, цвет
`allur`), рядом — название площадки «Сборочный завод · Костанай». На экране входа — крупный логотип
на тёмном блоке. Логотип не перекрашиваем, не растягиваем и не ставим на красный фон.
Иконка сайта — белая «a» из логотипа на красной плитке. Исходник — `frontend/public/brand/allur.svg`.

## Изометрический цех

`features/floor/IsoPlant.tsx` + геометрия в `features/floor/iso.ts`. Аффинная проекция (видны верх,
перед и правая грань), три слоя SVG: дальний статичный, слой движения (кузова, руки роботов,
мигающие аварии — свой слой композиции), ближний статичный с зонами клика; подписи участков — HTML.
Клик по оборудованию открывает риск отказа, клик по карточке участка или склада — его цифры и оборудование.
У сцены своя тёмная палитра (константа `S` в компоненте) — это иллюстрация, а не интерфейс;
состояния берутся из общих токенов (`--color-run`, `--color-down` …). Минимальная ширина сцены — 1180 px,
на узких экранах она прокручивается вбок внутри блока.

## Конструктор

`features/builder` — узловой редактор (React Flow). Узел — карточка с полосой состояния слева,
иконкой вида, выпуском, «в час», загрузкой и квадратиками оборудования (цвет — состояние, оранжевая
обводка — тревога датчика). Связи анимируются и краснеют, когда по ним идёт поток. При отдалении
(масштаб < 0,42) узлы становятся крупными цветными плашками с одним числом — схема на сотни станков
читается целиком.

Вид «3D» (`builder/Plant3D.tsx`) — та же проекция, что у «Цеха сейчас», но геометрия строится из
схемы: узел — площадка на месте карточки, оборудование — модель по полю «вид в 3D», связи — ленты.
Слои: пол и цех статичны, подсветка состояний и анимация изделий — отдельными слоями.

## Режим симуляции

Плеер (`features/sim/SimPanels.tsx`) — тёмный блок сверху «Цеха»; на остальных страницах — тёмная
полоса «Режим симуляции» под шапкой с кнопкой «В реальное время». Введённые события на таймлайне —
белые точки, случайные отказы — красные, поставка/брак — жёлтые.
