# Правила разработки «Цифровой двойник завода АЛЛЮР»

## Код
- Бэкенд: Python 3.12+, FastAPI, слои `api → services → analytics/sim → db`. Роуты тонкие: проверка прав и входных данных, вызов сервиса.
- Модель завода — только в `app/domain/plant.py`. Не дублировать коды участков и оборудования по коду.
- Аналитика — чистые функции от `Dataset`. Без сети и глобального состояния. Новый модуль — новый тест в `tests/test_analytics.py`.
- Все тексты для пользователя — на русском, понятным языком, с цифрами. Десятичные — через запятую (`app/core/text.ru`).
- Перед коммитом: `ruff check app tests`, `ruff format`, `pytest`; во фронтенде `npm run typecheck`.

## Безопасность
- Никаких ключей, PIN и паролей в коде, тестах и коммитах. Только `.env` (он в `.gitignore`), шаблон — `.env.example`.
- Каждый эндпоинт — с зависимостью прав (`ViewerDep`, `ShiftDep`, `ReporterDep`, `OperatorDep`, `AdminDep`, `UsersAdminDep`); права ролей — `GRANTS` в `app/core/security.py`.
- Деньги — только в тенге (₸), и в текстах ИИ-анализа тоже.
- Входные схемы — `Strict` (лишние поля запрещены), с ограничениями длины и диапазонов.
- Ошибки — через `AppError` и наследников; стектрейсы наружу не отдаём.
- Токен — только в заголовке `Authorization` или первом сообщении WebSocket, никогда в адресе.

## Интерфейс
- Дизайн-система — `docs/DESIGN.md`, токены — `frontend/src/styles/index.css`. Без хардкода цветов в компонентах.
- Каждый раздел — отдельный блок (`Panel`/`Tile`), блоки не сливаются: поле `paper`, между блоками 16px.
- Тёмный блок (`tone="deep"`) — только для главного на странице (живая линия); красный блок (`tone="brand"`) — один ключевой вывод (узкое место).
- Фирменный стиль Allur: красный (`brand`) — одно главное действие в блоке и бренд; данные на графиках — `accent` (тёмно-красный). Логотип Allur — только `AllurLogo`, цвет `allur`.
- Крупные цифры — Outfit light; подписи — Manrope, без капса.
- Состояния: run — зелёный, ждёт — серый, буфер полон — жёлтый, стоит — красный, обслуживание — фиолетовый. Статус всегда с иконкой или словом.
- Кнопки называют действие («Прогнать сценарий», «Завершить ремонт»).
- Проверять ширину 390 px: страница не должна прокручиваться вбок.
